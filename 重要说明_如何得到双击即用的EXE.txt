集装箱资料智能生成系统｜Windows EXE 云端构建包
================================================

重要说明：这个 ZIP 是修正后的 Windows 云端构建项目，不是已经编译并实机验证的 EXE 成品。
当前制作环境无法运行 Windows，不能在这里直接生成并验证 Windows EXE。

你不需要在自己的电脑安装 Python 或 Tesseract OCR。项目会在 GitHub 的 Windows 云端电脑
自动安装构建依赖、打包中文/英文 OCR 引擎，并生成可双击运行的 EXE。

一次性构建步骤：
1. 登录 https://github.com/ ，创建一个空仓库。
2. 解压本包，将文件夹内全部文件（包括隐藏的 .github 文件夹）上传到仓库根目录。
3. 打开仓库的 Actions 页面，选择 “Build Windows EXE”。
4. 点击 “Run workflow”，等待构建完成。
5. 在成功的运行记录底部 Artifacts 下载 Container-AI-Windows-Full-Package。
6. 解压后得到“集装箱资料智能生成系统_免费完整版.zip”，这才是给最终用户使用的成品包。

最终用户：解压成品包，双击“集装箱资料智能生成系统.exe”即可；不需要安装 Python，
不需要单独安装 OCR。第一次启动可能需要稍等几秒。

功能包括：ZIP 批量导入、照片 OCR、箱号分组、照片清单和预览、分类人工复核、
资料字段修改、选择 DOC/DOCX 模板、按箱号批量生成 Word、导出识别报告。

识别结果仍需人工复核；模糊、反光、倾斜照片可能影响 OCR 准确率。
