集装箱资料智能生成系统_免费分享版
================================

一、功能
- 支持选择一个或多个 ZIP 图片压缩包批量导入；
- OCR 尝试识别箱号及业务字段；
- 图片按箱号分组，支持人工调整照片类别；
- 选择 DOC/DOCX 模板，按箱号批量生成可编辑 Word；
- 未识别字段应留空并在核对页标记待补充，不得猜测。

二、测试案例 FORU6662703
测试资料文件夹内含原始 FORU6662703.zip（17张照片）、此前整理的核对稿，以及已知字段清单。
此前可确认：箱号 FORU6662703；箱型45G1；发站铜山站；到站二连（口岸站）；货物衣物干燥机；最大件重57KG；尺寸705×675×885mm。
境外到站、是否混装、托运人、发货人、件数、总重量均标记待核实。

三、Windows 使用
最终用户只需双击“集装箱资料智能生成系统.exe”，不需要安装 Python。
注意：本交付环境不是 Windows，不能在此直接生成并实机验证 Windows EXE。本包目前包含完整源码、模板、测试资料和 Windows 构建配置；正式 EXE 需要在 Windows x64 环境构建后放入本目录。

四、OCR 运行条件
程序会优先使用随 EXE 打包的 Tesseract；开发/源码运行时也会自动检查 C:\Program Files\Tesseract-OCR、Program Files (x86) 及 PATH。必须同时存在 tessdata\chi_sim.traineddata 与 tessdata\eng.traineddata。若缺少语言包，界面会显示具体原因。正式 EXE 应由 GitHub Actions 将便携版 Tesseract 与语言包一并打包，最终用户无需另装 Python 或 Tesseract。

五、运行步骤（生成 EXE 后）
1. 双击 EXE；
2. 点击“导入ZIP压缩包（支持批量）”；
3. 点击“选择Word模板”，选择模板目录中的 DOCX 模板；
4. 检查 OCR 字段、手动补充待核实数据并复核照片分类；
5. 点击“按箱号批量生成Word”，选择输出目录。

六、重要说明
- OCR 结果可能受照片清晰度、角度、反光影响；
- 图片分类为辅助判断，建议人工复核；
- 不确定的件数、总重量、最大件重、尺寸等业务数值不得凭经验补齐；
- 原始模板为旧版 DOC，同时提供转换后的 DOCX；若版式有差异，以业务方确认的正式模板为准。
- 当前自动识别属于辅助录入，不构成报关、铁路运输或海关申报数据的自动审核。
